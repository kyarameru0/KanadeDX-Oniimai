## Native and build-source material

Maven source JARs do not include all native implementation files. The dependency-source bundle also contains the AndroidX graphics-path 1.0.1 tree at `8a05a22af450d589ef911d772a001a49dcb05b71`, identified from the [official release notes](https://developer.android.com/jetpack/androidx/releases/graphics#graphics-path-1.0.1). The additional download and checksum are in [source-extras.json](../source-extras.json).

The compiled module statically links NDK runtime material. The complete notice supplied by NDK r27c is retained; NDK sources/build information are available from [Android NDK](https://android.googlesource.com/platform/ndk/+/refs/tags/ndk-r27c/README.md) and [Android toolchain/LLVM](https://android.googlesource.com/toolchain/llvm_android/). The SDK, NDK and complete upstream build infrastructures are not bundled. Do not describe the Maven source archive alone as a complete Android toolchain source distribution.

Run `python scripts/fetch_dependency_sources.py --output work/dependency-sources` to fetch the same upstream source artifacts and verify pinned SHA-256 values. This command does not execute downloaded code. Source archives retain their upstream headers and notices.

Source availability and license conditions still need to be maintained for every actual binary recipient. No public-distribution approval is implied by this inventory.
